# Phase 6 v2 (POST HOC): revised gate and abstention policy (2026-11-17)

Commit at run time: `50a346b9e27d85c96e585cc5359fc0eefbe70264`; rules and code tagged `phase6-v2-prereg` before this single test evaluation. Generated by `python -m src.uncertainty.phase6_v2`.

**This is a post-hoc round, decided after the v1 test results were seen.** The pre-registered result is v1 (`report/tables/abstention.md`, tag `phase6-v1`), reported unchanged. Everything here was fitted on the validation split (78 images) and evaluated once on test (121 images). Gold was not used. Same method and records as v1 (colour stage `denoise+shades_of_gray+exposure`); error = distance from the clean-photo estimate; flip rates use the PLACEHOLDER levels and mapping; corruption levels are placeholders.

Changes: (1) one overall false-retake target of 5% on clean validation photos, split evenly over the check sides, with the minimum side fitted inside that budget instead of the fixed 224 px; (2) a JPEG blockiness check; (3) coverage measured among gate-passed photos; (4) classifiers tuned and the policy score chosen by grouped cross-validation inside validation.
