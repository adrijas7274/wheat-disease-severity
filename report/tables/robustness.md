# Phase 4: cheap-phone corruption benchmark (2026-11-14)

Commit at run time: `473978801f4e4204b0c8a5b95a7e78b672c6ec24`. Generated by `python -m src.corruptions.benchmark`.

Every number compares a corrupted image with **the same model's result on the clean image** (severity shift, level accuracy, flip rate) or with the PlantSeg region mask (mIoU). Severity is the frozen Phase 3 method (C1, leaf from SAM 2) run end to end on the corrupted image. Click: on test images the automatic rule on `segformer`'s clean prediction; on gold images the rater's click.

**Placeholders:** the corruption levels (hand-set, not calibrated on real phones; level 3 of one corruption is not comparable with level 3 of another), the severity levels (none = 0%, low below 5%, medium below 20%, high above) and the decision mapping. The decision is one-to-one with the level, so flip rate = 1 - level accuracy. **Severity shift in points is the primary metric: it does not depend on any threshold.**

**The frozen severity method is about 14 points from the gold ratings** (`report/tables/gold_evaluation.md`), so this benchmark measures how stable the estimate is, not how correct it is.

Figures: `report/figures/robustness/`.
